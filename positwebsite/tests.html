My Little Board — Test Suite

// automated unit tests + manual interaction checklist

Manual / Interaction Tests

Clicking on empty board area creates a new sticky note at that position
New note has a random pastel color from the palette
Note text is editable — clicking the text area enters edit mode
Dragging a note moves it smoothly across the board
Scrolling mouse wheel over a note rotates it
Notes snap to sensible rotation increments or rotate freely (consistent behavior)
Each note has a task list — clicking "Add task" adds a new task item
Checking a task item marks it as done (strikethrough / checked state)
Unchecking a task item restores it to pending
Deleting a task item removes it from the list
Closing / deleting a note removes it from the board
All notes and their positions persist after page reload (localStorage)
Task state (checked/unchecked) persists after page reload
Rotation angle persists after page reload
Board can hold multiple notes simultaneously without overlap issues
Dot-grid background renders correctly and does not scroll with notes
Caveat handwriting font loads (Google Fonts) — text appears in script style
App works offline after first load (no external runtime dependencies other than font)
Notes do not overflow outside the viewport in an unrecoverable way
Responsive: usable on a 375px wide mobile screen (touch drag works)
No console errors during normal use
