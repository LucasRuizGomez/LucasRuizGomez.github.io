What You Get // Feature Overview
♪
AudioSend VST3
Loads in your DAW like any other VST3 plugin on Windows. Tested in FL Studio. No separate app, no account, no configuration required.
≈≈
Local Network Transfer
The plugin opens a local server when your DAW loads it. Scan the QR code once from your phone. Turn on Auto-watch and every export saved to the watch folder appears on your phone. Stream it, download it, done.
##
Built-in Audio Analysis
LUFS, true peak, dynamic range, stereo width, phase correlation, L/R RMS, DC offset, spectral balance — on the same page where you're listening. Real data, no extra tools.
>>
Free and Open Source
No price, no subscription, no license key. The full source code is on GitHub under the AGPLv3, built with C++ and JUCE.
